## 建议 PR 标题

Add local CLI/MCP automation, native chart workspaces and a reusable cross-platform desktop UI

## PR 描述草稿

### Change and user behavior

EasySellPut now exposes its local market and portfolio workflows through a shared application layer, a cross-platform CLI and a read-only-by-default stdio MCP server. Desktop workflows gain native embedded chart/news workspaces, editable website tabs, reusable UI components, market glance panels, background lifecycle control and verified update installation. User data remains local.

The branch includes all upstream 0.5.3 commits. Async database integration additionally rejects stale IV/option UI continuations after cancellation. The intended application version remains 0.6.0.

### Entry-point coverage

- Desktop: Windows WPF and macOS Avalonia use shared design tokens and primitives; bundled chart surfaces retain native WebView boundaries. Window layout, article split, website tabs, OS status panels and animation are documented presentation-only exceptions.
- CLI: 45 typed application operations, human/JSON output, common data directory, bounded execution and structured provenance/errors. Self-contained distributions cover five OS/architecture targets.
- MCP: official SDK stdio transport uses the same catalog and application services. Write tools are hidden and rejected unless explicitly enabled. Companion skill and scenarios track the entire compiled catalog.

### Validation

Local headless, storage/provider fixtures, real CLI/MCP process parity and full shared integration tests pass; see the linked sync report for exact counts. A separate deliberate live-provider run passed 16 checks across both transports. Cross-platform native WebView/package/GUI results must be attached from the merge commit's CI; cross-compilation is not native execution.

### Maintainer handoff before release

Update signing currently trusts the fork's fixed release identity. Before an upstream release, select the upstream official repository and matching embedded public key/signing secret, then verify install/rollback end to end. Preserve bundled third-party notices and fonts/licenses. Do not publish an upstream binary that silently follows fork updates.

建议审查顺序：共享层/CLI/MCP与数据协议 → 图表/期权/新闻交互 → 组件与全页面布局 → 平台生命周期/更新/CI。体量较大，第三方资产与生成审计清单应单独查看，避免掩盖业务差异。
