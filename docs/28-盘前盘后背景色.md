# 盘前/盘后背景色

- 日内图：盘前用低饱和蓝紫底色，盘后用低饱和琥珀底色，常规时段保留主题底色。
- C# WebChartSnapshot 复用 Core/MarketClock 的美股标准时段分类，输出每根 K 线起始时间的 session。美东夏令时、周末和全日假日沿用共享交易时钟；不在 JavaScript 再实现市场日历。
- 标准时段：04:00–09:30 盘前、09:30–16:00 常规、16:00–20:00 盘后（美东）。提前收市未建模，图例详情明确说明。小时线等聚合柱按起始时间分类。
- TradingView pane primitive 在每个实际面板底层绘制，不覆盖蜡烛、指标、网格、事件及交互。不插入或制造行情；仅绘制已加载柱覆盖的背景区域。
- 背景使用实际柱时间坐标与当前 barSpacing，随缩放/平移/窗口尺寸/像素密度调整；支持主题切换与指标面板重建。
- 顶部小色块展示图例，点击或键盘可展开标准时间和限制；光标行情显示对应时段。日线/周线/月线不显示日内背景。
- 颜色集中在 ThemePalette，保持与涨跌语义色分离。

桌面：纯图表呈现。CLI/MCP：已有 get_bars/get_chart_analysis 继续返回原始时间及行情，不改公共接口，也不新增颜色/窗口控制工具。时段规则沿用共享 Core，私有 WebView payload 增加兼容字段。

验证：48 个 Shared 测试；实际 Chromium 的渲染器、时间线及新增 test_sessions.py（8 项），后者通过生产 C# 通道核对盘前/常规/盘后数量、实际 Canvas 像素差异、五面板绘制、缩放、主题、图例键盘、指标重建及日线禁用。原生四架构 WebView smoke 追加 session primitive 校验，CI 自动执行新增浏览器测试。Windows 编译单独验证；原生运行结果以 Actions 为准。
