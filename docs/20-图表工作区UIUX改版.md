# 图表工作区 UI/UX 改版

参考 TradingView 的工作区分区与交互习惯，保留 EasySellPut 自身功能与 TradingView Lightweight Charts 署名。

## 布局

- 顶部两行：标的输入、加载、指标与设置、刷新、导出；其下是周期切换。
- 左侧：应用导航收窄但保留文字；图表内部独立画线工具栏，选中状态跟随画线模式，画线完成后自动退出。
- 中央：图表优先占据剩余空间；默认价格图与成交量约为 4:1，多指标时保留可读的子面板。移除重复标题与教学段落，复权依据和来源继续显示在状态行。
- 右侧：指标、参数、对比和复权设置按需展开；事件与新闻在宽图表中使用独立侧栏，在窄图表中回到底部。
- 底部：来源、复权依据、加载与错误状态；网络诊断放到来源状态提示中，数据目录仍在设置页可查。

全局使用共享 ThemePalette：白色/中性灰浅色界面、深蓝灰暗色界面、蓝色操作与选中态。保留用户选择的红涨/绿涨约定、语义警告和数据来源。参数、复权、指标计算、画线存储与事件时间语义沿用原有应用层。

## CLI / MCP 适用性

本次修改为桌面布局与呈现，不新增业务能力或 MCP 窗口控制。已有 `get_chart_analysis`、`get_market_events`、`get_chart_drawings`、`add_chart_drawing`、`clear_chart_drawings` 和 `update_preferences` 保持原有契约。桌面能力清单补充了侧栏和画线模式的呈现说明，现有实际 CLI/MCP 用例继续执行。

Headless 截图不包含系统 WebView 的真实渲染；图表渲染证据来自真实 Chromium 和四架构原生 CI。测试截图采用确定性 fixture 数据，不代表实时行情验证。
