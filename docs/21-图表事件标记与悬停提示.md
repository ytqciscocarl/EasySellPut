# 图表事件标记与悬停提示

图表事件保留原有应用层数据与时间对齐逻辑，仅改进呈现：

- 新闻圆点、财报方块、除息向下箭头，配合文字和类型配色；筛选区显示同样的形状图例。
- 同一 K 线上的多个事件显示类型组合与总数，不再只显示一个无法解释的数字。选中事件用前缀和高亮表示。
- 悬停相关 K 线或事件标记，显示原始事件时间、标题、来源与日历事件的确认状态。周期汇总或对齐后续 K 线时说明标记位置不等于原始时间。
- 点击图表继续在侧栏查看详情；键盘可通过侧栏事件列表访问相同信息。提示框不接收指针，不影响图表点击或画线；画线时隐藏提示。
- 提示使用 textContent，不执行新闻/provider 文本。移出图表、滚轮、Escape、事件筛选或数据刷新会隐藏旧提示。窄窗口中限制宽度和事件数量，长标题截断，完整内容通过侧栏查看。

CLI/MCP 不新增操作：`get_market_events` 返回的类型、时间、确认状态和来源契约保持原样。Tooltip 和标记样式是桌面呈现；不增加远程窗口控制或任意 URL 工具。

验证包括真实 Chromium 的悬停、点击详情、同柱多事件、主题/语言切换、文本转义、Escape、窄窗口边界及图表回归。截图使用 fixture 数据，不代表实时行情。原生系统 WebView 检查由 Windows/macOS 四架构必需 CI 执行。
