# macOS 菜单栏股价

启动 Mac 客户端后，系统菜单栏显示当前标的、常规／收盘价、涨跌方向及幅度。例如 `NVDA 162.85 ↑1.20% · 15m`；`15m` 是来源声明的延迟，`?` 表示时效未知，失败或陈旧值带“旧 / stale”。来源没有提供涨跌幅且无法从昨收计算时不显示百分比。盘前盘后报价在菜单中单独标记，不混用常规价格。

点击菜单栏可查看币种、来源、行情时间和抓取时间，打开当前标的图表、刷新、隐藏主窗口、切换自选标的或退出。标的跟随桌面当前选择，本轮不新增持久化设置。需要关闭窗口后继续运行时，可在原有设置中选择隐藏到后台；菜单中的隐藏主窗口无需更改关闭行为。应用真正退出后移除菜单栏项；不新增开机自启或常驻守护进程。

行情订阅加入现有 QuoteHub，使用既有 QuotePump 和交易时段刷新节奏。菜单栏不是独立实时行情源，实时性由数据源决定；不新增轮询或重复提醒监控。后台运行沿用 App Nap 活动机制，不阻止系统睡眠。

## 入口适用性与验证

该 OS 呈现仅适用于 macOS。Windows 界面、CLI 和 MCP 的数据契约保持不变；`get_quotes` 与 `get_watchlists` 已覆盖底层数据，不增加远程菜单/窗口控制工具。壳能力清单记录了此映射。

单元测试验证非有限/缺失价格、延迟、未知涨跌、陈旧值、盘后价格分离、标的切换和订阅释放。macOS 两架构原生 smoke 验证 NSStatusItem、原生菜单 target/action、颜色约定、缺失/陈旧值、创建/销毁和 AppKit 按钮 PNG 截图。产物随 CI 上传；截图是明确的 fixture 报价，不代表实时行情成功。
