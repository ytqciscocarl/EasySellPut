## 使用

点最左侧 `+`，填写名称和 HTTP/HTTPS 网址并保存。点击网页图标打开，在地址栏更换地址只改变当前浏览位置；需要修改固定入口时点工具栏 `⋯`，或右键图标进入管理。编辑窗口可排序或移除，点击最上方应用图标返回原来的市场页。网址中不能包含内嵌用户名/密码。

仅名称、固定网址、顺序和减少动态效果偏好保存在数据目录的 `web-workspace.json`。网页正文、登录信息和浏览历史不写入这个文件；网页会话使用系统 WebView 的临时存储，退出后清除。第三方网站可能限制嵌入式浏览器或登录，保留显式外部打开和加载错误提示。

## 实现与边界

桌面使用 WKWebView / Evergreen WebView2，不打包 Chromium。隐藏网页保留原生控件，首次打开才消耗浏览器资源，最多 12 个固定入口。切换到网页时市场页走正常卸载/停用流程；不启动第二套行情或提醒循环。动画仅用于导航 chrome，不对原生网页做位移/整页截图动画，不增加逐帧计时器。原生 macOS 系统减少动态效果在窗口激活和页面切换时读取，Windows 在每次动画触发时读取。

UI-only 适用性：这些是本地桌面收藏及展示偏好，无新增市场业务、CLI 命令或 MCP 工具。明确不提供任意 URL 执行、远程网页读取、cookie/登录会话访问或窗口控制工具；现有行情、新闻和日历业务工具保持原合同。已更新 desktop_capabilities.json 和 AGENTS.md。
