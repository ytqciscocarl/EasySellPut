# 新闻分屏阅读

新闻页、K 线事件和图表新闻侧栏共用主窗口内的阅读分屏，不再创建额外新闻窗口。原页面保持在工作区中；再次打开新闻复用同一个阅读区域。

- 所有窗口均左右并排，窄窗口也不自动切换为上下排列。分隔线可拖动，阅读与主页面均保留最小空间。
- 原文头部仅显示来源域名，配有居中的 Lucide 刷新、外部打开、关闭图标。完整地址和标题放在来源提示中，不再显示地址输入框、后退/前进工具栏或常驻安全说明。
- 关闭按钮或 Escape 关闭阅读区域，原页面恢复完整空间。窗口隐藏或最小化时，原生浏览器沿用后台暂停策略。
- 分屏切换方向和调整大小不重建 WebView，不重载原文；关闭阅读区域才释放它。个人网页标签继续使用完整地址/历史导航模式。
- 原文属于发布方页面，广告、排版与登录由发布方控制；不向远程新闻注入脚本、样式或图表桥接。

实现复用 ArticleSplitView 与 WebTabPane 的 articleMode，保留 WKWebView/WebView2 的协议限制、弹窗拦截、下载与权限拒绝、独立浏览会话及无宿主对象/消息桥接策略。

验证包括两端实际界面测试（同一浏览器实例、无地址框、三个图标、宽窄窗口的左右布局、关闭与不安全地址），以及四架构原生浏览器测试（实际原文加载、调整大小不重载、暂停恢复与历史/安全策略）。Windows 新增本地 HTTP 新闻 fixture 和真实桌面像素截图，确保截图包含 WebView2 正文，而非 RenderTargetBitmap 无法捕获的 HWND 空白；截图使用明确标识的演示新闻与测试行情。

该功能属于桌面展示，不增加 CLI/MCP 窗口控制操作。文章元数据与原文链接仍由既有 get_news/get_market_events 提供，保留全部能力对照检查。旧 NewsReaderWindow 仅保留为既有原生浏览器安全测试宿主，正常用户入口不再引用。
