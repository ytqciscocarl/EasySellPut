# 行情速览与跨平台托盘

## 交付范围

把原有“报价文字＋系统菜单”升级为行情面板。采用常见的交易终端速览分区，而非继续堆叠菜单文字；保持应用现有字体、配色、Lucide 图标和涨跌色约定。

- macOS：状态栏仍保留当前标的报价；点击打开行情速览，点击标的切换状态栏和主图上下文。
- Windows：复用现有 H.NotifyIcon 托盘；左键打开速览，右键保留主窗口/退出并增加速览入口。悬停显示当前标的报价与来源/行情时间。Windows 没有与 NSStatusItem 等价的原生常驻文字区域，因此不注入 Explorer、不使用 deskband 或额外安装服务；通过固定悬浮窗口提供随时可见的行情。
- 两端均支持固定悬浮、标题拖动、Esc/关闭、分页、自选入口、选中标的打开完整图表。

## 组件与操作

| 区域 | 内容 | 操作与状态 |
|---|---|---|
| 顶栏 | 市场速览、固定、刷新、关闭 | 固定后失焦继续显示；未固定失焦收起；关闭不退出主程序 |
| 主标的 | 代码/公司、常规或收盘价、绝对涨跌与百分比 | 数据基准明确，不把盘前后价替换成常规价 |
| 时效 | 来源、延迟、货币、行情时间 | 来源声明不够时保留未知；请求失败保留上次报价并标记陈旧 |
| 盘前后 | 独立价格与独立时间 | 仅有真实有效扩展时段报价时显示，未知时间不会补造 |
| 分时主图 | 实际交易日、5 分钟常规时段走势、昨收参考虚线、末点 | 固定 09:30–16:00 ET 时间轴，未发生的时间不延伸线段 |
| 摘要 | 开盘/最高/最低/成交量 | 使用报价原字段，缺失为 —，成交量使用紧凑单位 |
| 自选列表 | 每行公司、价格、涨跌、迷你分时、实际日期、延迟提示 | 点击切换主图/状态栏；双击打开完整图表；行 tooltip 包含独立报价/图表来源与时间 |
| 页脚 | 页码、上一页/下一页、打开图表、自选、更多 | 每页最多 8 个，所有自选都能翻页访问；更多可退出应用 |

## 数据与性能边界

`QuotePanelViewModel` 为两端共享的可见性订阅控制；`IntradaySparkline` 是原始分时序列的展示投影。`QuoteSparkline` 分别调用 Avalonia/WPF 的原生绘图 API，不引入额外 WebView 或浏览器内核。

- 报价继续通过同一个 QuoteHub/QuotePump 合并获取；Windows 仅增加当前标的托盘订阅，面板仅订阅当前页。不会另启行情/提醒定时器。
- 分时请求复用原数据服务及 SQLite 缓存，请求最近 10 天以覆盖周末/休市；显示最新实际存在的常规交易日。主报价与图表的来源和时间分别保留。
- 仅可见时取分时，最多两个并发，自动更新不高于每分钟一次，单轮 35 秒取消上限。隐藏、翻页、换页集和退出取消旧轮次；迟到结果不能覆盖新轮次。
- 隐藏后不为该面板请求分时。重新打开优先使用一分钟内缓存；手动刷新可以重试。取消中的图表不记为已成功缓存。
- 缺失、非有限值、长时间间隙不画假直线；日线不伪装分时；平价线居中；未来数据不绘制。价格/曲线不做数值插值动画。
- 延续共享按钮反馈与减少动态约定，只对标题等小型 chrome 做进入反馈，不淡入整幅行情或原生窗口。

## CLI / MCP 适用性

行情、分时原始数据和自选分别通过现有 `get_quotes`、`get_bars`、`get_watchlists` 暴露；本次没有新的业务指标或存储修改。原生托盘、窗口固定、鼠标位置、分页、桌面导航属于展示功能，不新增远程窗口控制工具。已更新 desktop_capabilities.json，继续要求全部 45 个业务操作通过真实 CLI/MCP 进程执行。

## 验收证据

- Shared：实际交易日与时段筛选、未来过滤、缺口、平价、未知昨收、日线排除。
- Avalonia：中英 × 明暗 4 组实际 Skia 截图；逐标的数据/曲线、标的选择、隐藏停止订阅、重新打开缓存、两并发上限、取消和分页。
- WPF：真实原生窗口显示、选择和隐藏释放订阅，加入 Windows 原生 CI 过滤器。
- 四架构打包执行：macOS 实际 NSStatusItem target/action 打开面板；Windows 实际窗口创建/关闭及托盘相关原生集成。既有系统 WebView 与提取后的 CLI/MCP 检查保留。
- 截图：`build/out/quote-panel/mac-quote-panel-{language}-{dark}.png`，为明确的测试行情，不代表真实交易报价。Native CI 是平台执行证据，不能据此声称已测量全部硬件的帧率或通知区域位置。

## 后续扩展

可进一步验证用户是否需要分组筛选、更多行内盘口、可调面板尺寸和持久固定位置。当前先提供完整报价/分时主路径，避免同时加入多个隐藏手势或要求用户安装 Windows 外壳插件。
