# 聚合事件点击与左右分屏修复

图表 tooltip 统计了同根 K 线的全部事件，但点击通过 find 只取得第一条，导致“28 项事件”与点击后的展示不一致。

现在 hover 和 click 共用 eventHitItems，以当前类型过滤条件和同一标记时间解析整组事件。点击多事件标记后：

- 右侧进入「所选 K 线 · 数量」范围，列出全部匹配项，保留原始发布时间分组与独立滚动。
- 不自动展开第一条详情。选择具体新闻后才显示详情，关闭单条详情仍保留整组列表。
- 返回箭头恢复全部事件。过滤变化会同步数量；当前组没有匹配项时退出组范围。
- 图表仍显示所有匹配标记；行情刷新保留当前组、列表滚动位置和焦点，切换标的/周期清除旧范围。

新闻阅读按用户要求始终左右分屏，窄窗口也不改为上下布局；拖动分隔线调整比例，切换新闻保持比例。继续复用原生浏览器和后台暂停机制，不增加原文地址工具栏或新闻弹窗。

验证：真实 Chromium + C# 私有图表通道复现 28 条新闻，检查 tooltip、实际鼠标点击、28 条完整列表、最后一条详情、刷新与关闭、同根 K 线混合事件类型过滤、返回全部。原有时间线/历史导航/来源元数据/主题与窄屏回归继续执行。macOS 和 Windows 分屏回归及四架构原生浏览器缩放检查同步改为始终左右布局。

无业务接口或存储契约变化；CLI/MCP 继续通过 get_market_events/get_news 提供完整事件数据，不增加窗口选择操作。
