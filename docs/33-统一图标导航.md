## 图标来源与居中

使用 lucide-static 1.73.0 的 48 个官方 SVG，下载时校验 npm SHA-512，保留原始文件、来源清单和完整 ISC/MIT 许可。`build/import-navigation-icons.py <已下载归档>` 可复现生成 C# 路径与内置 WebView SVG 组件；运行时无 npm 或 SVG 解析依赖，不拉取第三方图标。

两平台按原始 24×24 画布居中，保留 2px 圆头/圆角描边；侧栏显示 24px，底栏显示 18px。只缩放完整画布，不按各图标的墨迹边界拉伸。图标绑定实际控件前景色，跟随深浅主题和选中态；CI 校验 SVG 原始哈希、画布、生成几何与许可资源。


## 全应用图标审查

已检查并迁移 Windows/macOS 原生页面、设置卡片、数据源健康状态、自选排序、图表加载/画线工具、网页导航及 MCP 复制入口；图表内置右栏、事件类型/筛选、关闭、帮助和策略腿移除同样使用此固定版本。所有显式应用图标来自同一来源，保留完整画布，避免字体基线和操作系统字体差异。新闻阅读器原有文字按钮没有旧图标。

品牌 Logo、个人网页首字、操作系统/框架自身的窗口/下拉/排序控件以及金融图表数据标记不属于应用图标，保留原有语义。CI 新增旧字体/手写图标回退检查，并校验所有已命名图标存在于固定子集中；原生图标画廊覆盖全部图标解析、边界、居中及深浅背景。

本地验证：Windows WPF 编译通过；Avalonia 80 项测试、实际 Chromium 13 项交互测试和自动化 32 项检查通过。图标画廊、底栏、单侧栏及图表截图已逐项查看。Windows/macOS 原生系统 WebView 与打包验证由四架构 CI 执行。
