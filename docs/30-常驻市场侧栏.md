# 常驻市场侧栏

任务已实现：图表右侧始终保留市场面板，采用 TradingView 的内容面板 + 最右侧工具轨结构。动态、新闻、日历按钮使用现有事件筛选逻辑，支持键盘、可见标签、选中态与中英文。不是 TradingView 专有组件，也不引入其账户或行情服务。

保留日期分组、分段历史导航、独立滚动、原始时间与来源、估算日期、图表事件联动、原文阅读和数据覆盖说明。侧栏不再折叠；紧凑窗口缩小宽度而不移到底部。未加载完整历史的限制仍在数据范围中说明。

桌面：仅布局与已有筛选的快捷入口变化。CLI/MCP：没有新增业务操作；继续使用现有 get_news / get_market_events，窗口布局和滚动不适用自动化工具。

验证：真实 Chromium 通过生产 C# 私有图表通道测试默认常驻、三种视图、键盘、日期导航、详情、阅读、tooltip、主题/语言和紧凑布局。原生 WebView smoke 同时检查 permanent sidebar 和三个导航入口，由 Windows/macOS x64/ARM64 CI 执行。截图位于 build/out/permanent-sidebar（测试夹具，非实时行情）。
