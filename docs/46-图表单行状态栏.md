# Single chart status row

The chart previously stacked a WebView footer (“Controls” and a permanent TradingView link) above native source/adjustment/crosshair metadata. The WebView footer is removed. The native footer now owns one aligned row: reusable `AppHelp`, loading state, source, adjustment and crosshair values.

Source/adjustment/crosshair labels do not wrap; long values use ellipsis with the full text available in tooltips. Existing adjustment warnings remain explicitly visible when present. Chinese/English help describes zoom, pan, drawing selection/edit/delete and Escape using the shared help component.

The bundled chart's attribution logo remains enabled. A compact Lucide Info link in the chart header retains the TradingView component name, copyright and URL in its tooltip and accessible action; there is no permanent branding text row. The vendor LICENSE and NOTICE remain bundled. The existing typed `attribution` event still handles external opening; remote WebViews receive no additional capability.

Coverage: real Chromium verifies no footer, empty visible text on the attribution icon, visible/focusable/clickable link and compact bounds; all 15 chart/workbench/timeline/session/drawing cases pass. Both desktop suites include footer alignment/full-text/help checks at 980 and 1920 widths. Existing chart rendering and native split-view CI screenshots cover the final combined layout.
