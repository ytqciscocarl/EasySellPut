# 桌面自动打包与 AI 连接

本轮交付桌面包和连接入口。CI 在 Windows x64/ARM64、macOS Intel/Apple Silicon 原生 runner 上构建完整桌面包，并随包附带对应架构的自包含 CLI/MCP。未自动发布 GitHub Release，也未引入安装器或签名证书依赖。

## 使用

macOS 请先把 `.app` 移入“应用程序”再启动；检测到 App Translocation 临时路径时会禁用复制，避免生成退出后失效的配置。

设置页点击“复制 Codex 命令”，粘贴到已安装 Codex CLI 的终端执行；Windows 使用 PowerShell。命令注册名为 `easysellput` 的只读 stdio MCP。若已经有同名配置，先在 Codex 中检查原配置再决定是否替换，应用不会修改任何客户端配置文件。

“其他连接方式”提供 Codex 的 TOML 配置和通用 MCP JSON，可手动合并到相应客户端。默认不含 `--allow-writes`。连接使用包内 CLI 的绝对路径及桌面当前数据目录；移动安装包后需要重新复制配置。查询结果会传给连接的 AI 工具。配置示例不包含代理 URL 或凭据。

未附带 CLI 的开发构建会显示不可用状态并禁用复制按钮，不把猜测的路径当成可用连接。模板支持空格、中文、引号与非 BMP Unicode，POSIX shell / PowerShell 分别使用正确的字面量转义。应用只复制文本，不执行命令。

## CI 产物

从 Actions 成功运行底部下载 `Desktop-*`：

- `EasySellPut-Desktop-<版本>-win-x64.zip` / `win-arm64.zip`：自包含桌面程序与 `automation/easysellput.exe`。Windows 桌面需已安装 Evergreen WebView2，不捆绑 Chromium。
- `EasySellPut-Desktop-<版本>-osx-x64.zip` / `osx-arm64.zip`：`.app` 及包内 `Contents/Resources/automation/easysellput`，使用系统 WKWebView。Info.plist 最低系统为 macOS 15，原生 CI 分别验证 Intel/macOS 15 与 Apple Silicon/macOS 26。
- 每个压缩包有 `.zip.sha256`，Artifacts 保留 14 天；现有独立 `CLI-MCP-*` 包继续提供。

macOS CI 包仅 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证；Windows CI 包没有发布者签名。它们是可下载的验证产物，不宣称已完成正式签名分发流程。原有 Inno Setup / 跨平台脚本保留；新 CI 使用统一 `build/pack-desktop.py` 原生单架构构建，避免覆盖旧产物。

## 验证及边界

`tests/automation/check_desktop_package.py` 校验 SHA-256、可执行文件架构、运行时、图标/资源、WebView2 文件或 macOS 严格签名，从含空格路径解压后启动真实 GUI 自检，检查设置页、实际剪贴板及包内图表 WebView，再启动随桌面包分发的 CLI/MCP 执行真实进程测试。临时数据目录隔离用户设置与历史。

macOS 增加 `--smoke-offline` GUI 自检并输出 JSON；Windows 复用既有自检，增加 AI 连接与已打包图表检查。此诊断不会加载假行情，也不把离线自检视作实时行情验收；页面初始化仍可能尝试后台行情请求。CI 原生 WebView 的固定数据交互验收继续单独保留。

按钮属于桌面剪贴板和客户端配置引导，未增加业务 MCP 工具；已有 43 项业务目录保持不变。桌面能力清单增加三项界面例外，当前 17 个 view-model / 70 个 RelayCommand 均需审查。Application 的 `McpConnectionSetup` 为平台无关模板生成器；Python 使用 JSON、TOML 解析器与 shell 分词验证实际 C# 输出，Shared 验证按钮行为、缺少 CLI、当前目录、默认只读及语言更新。四架构桌面打包步骤纳入既有 `CLI and MCP required` 汇总检查。

后续独立工作：开发者证书/公证及正式安装器发布、定时真实行情检查、更多协议异常与存储压力测试、接口兼容性快照。此次不把这些后续项宣称为已完成。

后续接入现提供 Codex / Claude Code 的 Skill + MCP 组合命令，用户执行安装与注册。具体行为及项目级安装见 [Skill 与 MCP](19-Codex与ClaudeCode的Skill和MCP.md)；JSON/TOML 高级选项仍仅供手动 MCP 配置。
