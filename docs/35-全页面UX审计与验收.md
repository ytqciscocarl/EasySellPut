# 全页面 UX 深度审计、改造与验收报告

审计基线：`67f0357`。方法：静态逐控件盘点、实际 Avalonia/Skia 截图、键盘/指针测试、实际 Chromium + .NET fixture 主机、四架构系统 WebView/打包 CI。使用临时测试数据，未做真实用户访谈或线上转化/帧率统计。不得把启发式判断当作用户研究结论。

## 1. 结论与边界

主要问题是信息默认全部展开、重复教程、操作藏在隐含手势中，以及反馈在原生/HTML、指针/键盘、减少动态之间不一致。优先级：P0 保持状态/数据/可恢复性；P1 主路径直达和渐进披露；P2 有意义的局部动效和一致性。保留延迟、来源、缺失、复权、风险、运行限制和归属信息。

“每个操作有正确动画”解释为每个操作都必须有正确反馈：输入、拖动、价格、Canvas 和取消应立即响应，不能为了装饰增加延迟或虚构中间值。系统原生 popup/关闭已有动画时不叠加。

覆盖不是对任意金融参数做无限笛卡尔积；按组件状态、关键流程和风险等价类覆盖，完整交互控件目录见附录。报告中的“研究假设”不会冒称已实现/证明。

## 3. 通用组件、状态与动效规范

| 组件 | 反馈与动画 | 时长 | 禁止/验收 |
|---|---|---|---|
| 导航/底栏 | 选择、hover、focus、禁用均有反馈，布局稳定；图标不做持续跳动 | 120/180ms | 点击立即导航，无 WebView 淡入/平移 |
| 按钮/图标按钮 | 指针按压/释放和键盘激活同样有短反馈；快速连按可中断 | 120ms | 禁用立即生效，不让 animation 覆盖 disabled |
| 输入/自动补全 | 焦点/错误边框短过渡；输入、IME、方向键立即响应 | 120ms | 文字不做打字动画，不能 debounce 到阻断输入 |
| select/菜单/popup | 原生弹出/关闭保留；选中高亮清楚；Escape 返回焦点 | 系统/120ms | 不额外重放内容或双重动画 |
| 复选/开关/标签 | 有明确选中态和轻量背景变化 | 120ms | 不靠动画/颜色作唯一状态 |
| 卡片/报价/表格 | 内容及时更新；不对行情数字做补间 | 即时 | 价格不制造中间值，不让列表整体闪烁 |
| 折叠帮助/高级项 | 只淡入新出现的小块内容，保持滚动/选中态 | 180ms | 折叠字段值保留，键盘能展开 |
| drawer | 布局立即分配，只有自身原生 chrome 淡入 | 180ms | 不动画宽度/邻接 WebView；关闭立即交还焦点 |
| modal | 只对无 WebView 的本地内容进入做一次短淡入；退出交给系统 | 180ms | 确认/取消无延迟；Esc/owner/focus 保持 |
| loading | 可见时才转动；减少动态用静态活动标记 | 平台 | 不假造 50%，不常驻每帧定时器 |
| 成功/失败/复制 | 结果状态留在相关操作旁；动作反馈不等于任务成功 | 120ms | 失败有恢复入口，保留草稿/输入 |
| Canvas/高频图形/滑块/历史 | 交互响应优先于装饰；图表不做全页进场 | 即时 | 不改真实价格、指标或历史时间，不平滑拖慢十字线 |

所有组件还要检查 normal / hover / pressed / focused / disabled / loading / success / error / empty / selected。不是每个组件都应拥有全部状态；例如只读价格没有 pressed，而危险确认不能用自动消失提示代替明确确认。

## 8. 完整结构、动态组件与证据导航

- `docs/ux/components-before.json`：审计基线的每个原生声明节点、父子组合和属性，以及静态 HTML 控件。`components-after.json` 为改造后快照。模板实例按实际数据重复，不遗漏声明但不把每一条动态行情重复统计为一个新组件。
- HTML 动态组件：chain table（每合约买/卖、缺失参考价、禁用）、legs table（方向、数量、入场、单条删除）、payoff SVG（缩放、拖动、假设价、滑块）、event filter/type badge、event date group/history stop、event row、detail/close/original/metadata、drawing hint/editor/select/save/delete/cancel、coverage/error/status。它们分别由 workbench、timeline、drawings、renderer、sessions 实际浏览器测试覆盖，不以原生外壳空白 WebView 作为渲染证据。
- 交互式帮助使用平台 popup/flyout：默认不占说明行，按 Enter/Space/点击打开，支持 Esc/外点关闭；重要错误、监控运行限制、来源/延迟、模型和复权不依赖 hover。
- 组合布局保留规则：高密度金融表的横滚优先于缩小文字；必要换行只在宽度不足时发生；空状态保留第一个有效入口，禁用态保留标签，不让不可执行按钮静默无效。

CLI/MCP：新增的是报价卡导航、焦点、折叠/帮助及显示/校验反馈；原始行情空值、提醒边界与既有结构化 API 保持一致，不新增业务操作。Dashboard.OpenChart 已在 desktop_capabilities.json 记录 UI-only 例外。既有 45 项能力的真实 CLI/MCP 对照、权限、打包继续验收。
