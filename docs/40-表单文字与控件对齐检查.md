# 表单文字与控件对齐检查

## 修复原因

设置行的标题、帮助和输入控件分别由不同高度的 DockPanel/StackPanel 布局，标题文本默认靠顶部，而帮助按钮和下拉框各自居中，造成视觉偏移。固定利率还存在空错误提示占据行高的问题，即使没有错误也把标题顶偏。

## 统一规则与实现

新增双平台 AppFormHeader，组合既有 AppHelp 和标题文字：统一中心线、清除段落外边距、支持普通表单和页面大标题，保留完整的中英文帮助、键盘与 tooltip 行为。不改全局段落样式来掩盖局部问题。

设置页表单行将左侧标题组与右侧控件居中。下拉框和输入框使用唯一设计令牌 FormFieldWidth=260，帮助图标和输入列的边缘也一致。Windows AppCard 有标题时让内容按自身高度居中，无标题的普通卡片继续伸展内容。

固定利率使用独立网格行显示错误，空错误不占空间；正常、无效输入时标题/帮助/输入框保持同一中心线。错误文字在输入框下方，保留输入内容及已有验证逻辑。

## 其他页面检查

| 区域 | 结果 |
| --- | --- |
| 设置：语言、主题、涨跌色、关闭行为、代理模式/地址、利率模式/值 | 统一表单标题组件与输入列；正常及错误状态测量中心 |
| 设置：数据目录 | 标题与帮助合并成同一行，路径独立显示 |
| 设置：Codex / Claude Code 卡片标题 | 标题文字与右侧状态、帮助按钮居中 |
| 自选、期权、策略、新闻、价格提醒、数据源页面标题 | 共用 AppFormHeader，帮助图标与页面标题居中，保留原有外部间距 |
| 期权/策略工具栏行内标签 | 已有居中规则，保留；完整页面回归检查 |
| 提醒表单上置标签、统计数字上下说明、新闻多行标题、更新版本/状态 | 属于有意的多行信息层级，不机械改成行内居中 |

## 验收

- 双平台新增实际布局几何测试，比较文字、帮助和输入框的真实中心坐标，允许误差不超过 1px。
- 覆盖中英文、深浅主题、980/1440 宽度、固定利率空错误/有效错误，及其他六个页面标题。
- macOS 组件图库增加 AppFormHeader 实例，生成设置页截图；Windows 完整离线桌面回归自动包含新增测试。
- 更新生成式设计令牌、组件使用守卫与组件清单。样式和布局没有新增计时器、动画循环或业务操作。

CLI/MCP 适用性：本次仅调整展示组件与布局。现有偏好设置、行情与数据目录操作的协议、参数和持久化保持原有契约，继续运行完整能力对照 CI。
