# 单行工具栏与必要换行

- Windows/macOS 图表顶部合并为一行：标的输入与加载、周期选择、指标/刷新/导出。用三列布局固定左右操作，中间周期栏占剩余宽度。
- 周期按钮使用横向 StackPanel，避免自动换行。英文使用标准紧凑周期标签，完整名称仍由 tooltip 和无障碍名称提供。窄窗口保留可水平滚动的周期区域；重要操作不被隐藏，也不缩小字号。
- 检查相邻页面后，合并期权页“范围”与“显示列”中间强制换行，保留分隔符表达分组；空间确实不足时自然换行。
- 行情/来源状态与操作、参数标签与输入框的语义分组保留，不为追求单行而遮挡风险信息或使内容不可读。

这是桌面呈现改动，CLI/MCP 不新增业务操作，行情、事件和参数契约保持不变。验证覆盖双语、明暗主题、980×620 与 1320×840 窗口，检查周期按钮同处一行、工具栏高度、图表空间和 Windows 编译。原生四架构运行和打包由必需 CI 执行。
