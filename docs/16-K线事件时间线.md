## 使用

K 线页面下方展开“事件时间线”，筛选新闻、财报、除息；点击图表事件所在位置或列表条目查看详情。新闻原文通过现有内置阅读器打开。未来事件、无日期事件及当前图表范围外事件保留在列表，不制造未来 K 线。相同 K 线上的多个事件合并显示数量，可在列表逐项选择。

```sh
easysellput events AAPL --json
easysellput events AAPL --type earnings --from 2026-11-01 --to 2026-12-31 --limit 100 --json
```

MCP `get_market_events` 接收相同参数：必填 `symbol`；`type` 为 `all`（默认）、`news`、`earnings`、`ex_dividend`；可选 `from` / `to` 为包含边界的 YYYY-MM-DD；`limit` 默认 50，上限 100。默认只读即可发现、调用，不创建桌面窗口。

## 数据含义

复用已配置行情服务的最近最多 50 条新闻和当前 fundamentals 日历快照，无新付费源、浏览器引擎或第三方 JS 依赖。这不是历史公司行动档案，日期筛选不会向供应商补查历史新闻/历年财报；切换 K 线周期也不扩大事件历史覆盖。桌面事件独立于蜡烛图异步加载，五分钟内复用，退出页面取消请求，不重复运行行情循环。同步返回的事件合并进首次适应窗口绘制，异步返回的事件更新保留视图；K 线无变化且事件仍在复用期内时不重绘。

- `published`：来源给出的原始新闻发布时间；`date` 按美东日历推导。新闻缺少时间时保持 null，不以抓取时间填充。
- 财报/除息为日期型，`published` 保持 null；财报可能有 `endDate` 日期范围。
- `precision`：`timestamp` / `date` / `date_range` / `unknown`。
- `confirmation`：新闻为 `reported_published`；日历只有 Yahoo 明确的 `isEarningsDateEstimate` 才产生 `estimated` / `source_confirmed`，缺失标记及其他来源保持 `unverified`。过去日期不自动代表已确认。
- `source` / `publisher` / `providerAsOf` / `providerFetchedAt` 与本次读取时间 `observedAt` 分开；读取成功不证明实时。稳定 `id` 不含读取时间。
- `coverage` 逐类型报告 `available` / `empty` / `not_reported` / `unavailable`；`status` 为 `complete` / `partial` / `unavailable`。`complete` 仅表示本次请求未失败，不表示历史数据完整或通过实时联网验收。
- `truncated` 表示本次聚合结果超出请求 limit。新闻源本身仅返回最近有限条；`truncated=false` 不意味着该来源的所有历史新闻已取完。日期筛选排除的无日期条目数为 `undatedExcluded`。

图表另外返回渲染锚点与 `alignment`，不改原始事件时间。日线按美东日期，周末对齐下一可见交易日；分时新闻对齐不早于发布时间的后续已知 K 线；日期型事件按日期对齐；周/月线用 `period_bucket` 明示周期汇总。当前范围外或超出最后已知 K 线的事件不画标记。范围型财报只锚定起始日期，详情保留完整日期范围。事件线用真实 close 锚点，缺 OHLC 的柱也不会被补造为蜡烛。

## 安全与 UI

复用统一 ThemePalette、14px 正文/12px 说明、6px 控件、中英文、深浅主题和窄窗口布局。文本只使用 textContent，不把供应商标题/摘要作为 HTML。事件点击只传当前图表 key 与稳定 ID；C# 查找当前股票事件后，使用已有 HTTP/HTTPS 无凭据 URL 策略打开新闻阅读器。不接受前端提交任意 URL，远端新闻不获得图表私有通道权限。

`tests/Meili.Automation.Tests/MarketTimelineTests.cs` 检查精度、来源确认、稳定 ID、缺失时间、部分失败、筛选、数量、取消及 URL 策略。Data 测试验证供应商明确预计/确认/未知标记；Shared 测试验证周末、盘后、未来/无时间锚点、错误股票与延迟响应保护。

固定数据测试不等同于真实行情联网验证；本次复用既有供应商，没有声称免费来源拥有完整历史日历。

## 界面精简

默认只显示事件列表、日期和必要状态，选中后展示详情与阅读原文入口；收起详情后焦点返回原条目。来源时间、精度及对齐说明放入“数据详情”，历史覆盖限制放入“数据范围”。选中事件的图表标记改为方形，列表同时显示选中边框，避免仅靠颜色表达。类型筛选隐藏当前条目时自动收起详情，不替用户选中其他事件。

本次仅调整桌面呈现与交互，CLI/MCP 的事件数据、schema 和业务行为保持不变，无需新增操作或能力场景；原有 28 项双传输场景继续由必需 CI 验证。真实浏览器回归新增默认视图、按需展开、键盘打开/关闭与焦点返回、筛选清除选中态及图表标记联动断言；原生四架构 WebView 验收继续运行。
