# 图表工作区渐进式信息呈现

本轮继续精简图表工作区，而非删掉解释数据所必需的信息。

- 桌面画线工具使用实际线形图标与短标签；选中、悬停和键盘焦点由共享主题控制。标的旁的回车操作保留可访问名称，指标入口缩短。
- 事件类型筛选改为紧凑选项，形状和文字共同表示类型，背景/边框表示是否启用，仍使用原生 checkbox 语义与键盘操作。
- 事件列表采用图标、标题、时间的层级；长标题两行预览，选中后查看全文。来源确认状态、图外事件和未知时间仍明确显示。
- 详情关闭使用通用关闭图形，保留可访问名称；来源与精确时间按需展开。事件 tooltip 保留数量、原始时间、来源和估计状态，缩短重复指令。
- 图表底部常驻操作说明改为可点击/键盘展开的“操作”入口；TradingView 署名始终可见。

桌面 UI 改动不新增业务操作；CLI/MCP 的行情、事件、参数与持久化语义保持不变。无新窗口控制、数据写入或网络请求。

验证覆盖实际 Chromium 的筛选、键盘帮助、事件 tooltip 和窄窗口，以及原生壳的双语、明暗主题与最小尺寸布局。截图使用临时 fixture 数据；headless 桌面截图不代表系统 WebView 渲染。四架构原生验证与打包仍由必需 CI 执行。
